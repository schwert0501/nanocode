# 算子数据分析 · 标准流程

> 当用户提出「分析算子某指标 / 取一段数据 / 做报表 / 排查数据异常」等需求时，按本流程执行。

## 1. 需求澄清（动手前先确认，避免返工）
- 分析对象：是哪个业务模块 / 哪张表 / 哪个指标？
- 时间范围：起止日期、粒度（天 / 周 / 月）？
- 口径定义：指标怎么算？是否要去重 / 去测试数据 / 剔除内部账号？
- 维度拆分：要按哪些维度分组（渠道、车型、城市……）？
- 交付形态：原始明细、聚合结果、还是图表 / 看板？

## 2. 取数
- 优先复用已有的中间表 / 指标口径，不要重复造轮子（先 kb_search 查团队口径）。
- 写 SQL 时：显式写字段名（不用 `select *`）、加时间分区过滤、大表先 `limit` 验证。
- 参数化查询，避免把日期/ID 之类直接拼进字符串。

## 3. 校验（出数后必做）
- [ ] 行数 / 量级是否符合预期（和历史对比有没有突增突降）？
- [ ] 是否有 null / 重复 / 测试数据混入？
- [ ] 总量能否和已知口径（如总 DAU）对上账？
- [ ] 维度拆分后各分组加总 = 总量？

## 4. 交付
- 结论先行：先给结论/异常点，再附数据与口径说明。
- 附上口径与 SQL，保证可复现。
- 发现异常时，给出可能原因与下一步排查建议，而不是只抛数字。
